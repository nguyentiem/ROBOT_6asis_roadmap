Bài 6.1 · Động học robot

Mô hình robot URDF (Unified Robot Description Format)

mọi simulator và MoveIt đều cần mô hình robot; đọc được URDF là biết robot có bao nhiêu khớp, giới hạn bao nhiêu, và tại sao mô phỏng chạy lạ (sai khối lượng, sai trục).

01

Mục tiêu bài học

Sau bài này, bạn sẽ giải thích và vận dụng được:

  • URDF là gì: file XML mô tả robot (khâu, khớp, hình dạng, khối lượng) để mô phỏng, hiển thị và lập kế hoạch; dùng trong ROS, PyBullet, Gazebo, MuJoCo (qua chuyển đổi)
  • Hai thành phần chính: <link> (khâu) và <joint> (khớp); robot là một cây (tree) với một link gốc (base_link)
  • Link gồm 3 phần: <visual> (hình hiển thị), <collision> (hình dùng tính va chạm, thường đơn giản hơn), <inertial> (khối lượng, khối tâm, ma trận quán tính)
  • Joint: tên, loại (revolute, continuous, prismatic, fixed, floating, planar), <parent>, <child>, <origin xyz rpy> (vị trí/hướng của khớp so với link cha), <axis xyz>, <limit lower upper effort velocity>
  • Hình học: box, cylinder, sphere, mesh (STL/DAE/OBJ); đơn vị mét, radian, kilogam

03

Khái niệm cốt lõi

  • URDF là gì: file XML mô tả robot (khâu, khớp, hình dạng, khối lượng) để mô phỏng, hiển thị và lập kế hoạch; dùng trong ROS, PyBullet, Gazebo, MuJoCo (qua chuyển đổi)
  • Hai thành phần chính: <link> (khâu) và <joint> (khớp); robot là một cây (tree) với một link gốc (base_link)
  • Link gồm 3 phần: <visual> (hình hiển thị), <collision> (hình dùng tính va chạm, thường đơn giản hơn), <inertial> (khối lượng, khối tâm, ma trận quán tính)
  • Joint: tên, loại (revolute, continuous, prismatic, fixed, floating, planar), <parent>, <child>, <origin xyz rpy> (vị trí/hướng của khớp so với link cha), <axis xyz>, <limit lower upper effort velocity>
  • Hình học: box, cylinder, sphere, mesh (STL/DAE/OBJ); đơn vị mét, radian, kilogam
  • Liên hệ với bài 2.2: URDF dùng origin + axis thay vì bảng DH; cách chuyển giữa hai cách mô tả (mỗi joint = một biến đổi T cố định từ origin, rồi quay quanh axis)
  • Cách đọc cây: từ base_link đi qua từng joint tới tool0 / end-effector link; hệ tọa độ của link = hệ tọa độ của joint con
  • Giới hạn khớp: lower/upper (rad), velocity (rad/s), effort (N·m); khớp continuous không giới hạn góc
  • Xacro (giới thiệu): macro, biến, tham số hóa để URDF gọn hơn
  • Lỗi hay gặp khi tự viết URDF: quên inertial, sai đơn vị, khối lượng bằng 0, collision lệch visual, đường dẫn mesh sai
  • Công cụ kiểm tra: check_urdf, urdf_to_graphiz, hiển thị bằng PyBullet / RViz / urdf-viz
💡 Công thức/quan hệ trung tâm: T parent→child = T origin · R trục(q)

Đi sâu · Ba lớp của một khâu URDF

visual quyết định robot trông thế nào; collision là hình dùng phát hiện va chạm, thường giản lược để tính nhanh; inertial chứa khối lượng, tâm khối và tensor quán tính cho mô phỏng động lực học. Cả ba có origin riêng so với frame của link. Không thể thay collision bằng visual phức tạp rồi giả định mô phỏng vẫn nhanh hoặc ổn định.

Joint nối parent và child; origin đặt frame khớp, axis là hướng chuyển động trong frame đó, limit đặt góc/độ dời, tốc độ và effort. URDF tạo cây không có vòng kín trực tiếp. Đơn vị SI: mét, radian, kg. Đổi một chiều dài phải kiểm lại visual, collision, inertial và FK/TF liên quan.

06

Code Python

Python · ví dụ có thể copy
# URDF là XML. Ví dụ một khớp quay (lưu vào robot.urdf):
URDF = """<robot name="two_link"><link name="base"/><link name="arm"/>
<joint name="joint1" type="revolute"><parent link="base"/>
<child link="arm"/><origin xyz="0 0 0" rpy="0 0 0"/>
<axis xyz="0 0 1"/><limit lower="-3.14" upper="3.14" effort="1" velocity="1"/>
</joint></robot>"""
import xml.etree.ElementTree as ET
root=ET.fromstring(URDF)
print([j.attrib['name'] for j in root.findall('joint')])
07

Lỗi thường gặp

nhầm đơn vị mm/m, quên <inertial> hoặc khối lượng 0 (robot đổ/biến mất khi mô phỏng), collision quá phức tạp làm mô phỏng chậm, đường dẫn mesh sai (hiện robot không có hình), nhầm trục quay trong <axis> (xoay sai chiều), origin cha/con nhầm hệ, quên rằng joint origin tính theo hệ link cha, thiếu limit cho revolute (lỗi khi nạp), nhầm joint "fixed" với "revolute", dùng pybullet_data sai tên file.

01

Mục tiêu bài học

  • Viết hàm động học thuận (forward kinematics, FK) nhận sáu góc q và trả ma trận 4×4.
  • Tính các hệ trung gian T₀¹…T₀⁶, đọc vị trí và hướng, thêm base/tool/TCP.
  • Kiểm chứng bằng tư thế đặc biệt, tính chất ma trận xoay và mô hình Robotics Toolbox.
  • Nhận biết offset, giới hạn khớp, thứ tự nhân và quy ước DH khi debug.
02

Vì sao cần học?

Encoder cho biết sáu góc động cơ. FK biến chúng thành vị trí và hướng của đầu công cụ. Đây là cầu nối sang động học nghịch (IK), Jacobian và lập kế hoạch quỹ đạo. Với một bộ q và mô hình xác định, FK cho đúng một tư thế T; IK có thể có nhiều nghiệm.

💡 Ý chính: Nhân từng biến đổi từ đế tới mặt bích, rồi thêm biến đổi base và tool nếu hệ quan sát hoặc TCP khác mặc định.
03

Khái niệm cốt lõi

Với DH chuẩn, mỗi hàng (aᵢ,dᵢ,αᵢ,θᵢ) tạo Aᵢ = Rz(θᵢ) Tz(dᵢ) Tx(aᵢ) Rx(αᵢ). Nhân từ trái sang phải:

T₀⁶ = A₁A₂A₃A₄A₅A₆T_world^TCP = T_base T₀⁶ T_tool

Ma trận T = [R p; 0 0 0 1] chứa hướng R ở khối 3×3 và vị trí p ở cột 4. RPY trong bài dùng quy ước ZYX: R=Rz(yaw)Ry(pitch)Rx(roll), có nhánh đặc biệt khi pitch≈±90°; quaternion tránh biểu diễn góc đó. Xem thêm bài 1.3.

⚠️ Giá trị UR5 dưới đây lấy từ bảng DH chuẩn của Universal Robots: d₁=0.089159, a₂=−0.425, a₃=−0.39225, d₄=0.10915, d₅=0.09465, d₆=0.0823 m. Prompt cho các giá trị làm tròn; bài dùng số của hãng. Mô hình RTB có thể có base/tool hoặc quy ước khác, nên phải so bảng trước khi so ma trận.

Puma 560: cùng thuật toán FK 6 khớp, nhưng bảng DH, offset và hình học khác UR5. Chỉ thay bảng thông số sau khi xác định đúng quy ước.

Ví dụ có lời giải

  1. 2R phẳng: l₁=l₂=1, θ₁=30°, θ₂=45°. T₀²: x=cos30°+cos75°, y=sin30°+sin75°Vậy p≈(1.125,1.466) m, hướng 75°.
  2. UR5 ở q=0: nhân sáu Aᵢ theo bảng hãng thu p mặt bích≈(−0.81725, −0.19145, −0.005491) m. Hai a âm đặt cánh tay về phía x âm; d₄,d₅ tạo độ dời theo các trục trung gian. TCP có tool z=0.15 m sẽ khác mặt bích.
  3. Đọc T và đối chiếu: chọn preset “Home”, đọc cột cam của T là p, khối xanh là R; lấy RPY ZYX. Trong Python so với rtb.models.DH.UR5().fkine(q).A bằng np.allclose sau khi kiểm tra base/tool và bảng DH.
06

Code Python

Hàm dưới đây trả cả ma trận TCP, ma trận mặt bích và mọi hệ trung gian để kiểm chứng từng bước.

Python · NumPy
import numpy as np
import matplotlib.pyplot as plt
# Dùng SI (m, rad), DH chuẩn của UR5 do Universal Robots công bố.
DH = np.array([[0, .089159, np.pi/2],
               [-.425, 0, 0], [-.39225, 0, 0],
               [0, .10915, np.pi/2],
               [0, .09465, -np.pi/2], [0, .0823, 0]])  # a,d,alpha
OFFSET = np.zeros(6)
QLIM = np.deg2rad(np.array([[-360,360]]*6))  # giới hạn phần mềm minh họa

def dh_matrix(theta, d, a, alpha):
    c, s = np.cos(theta), np.sin(theta)
    ca, sa = np.cos(alpha), np.sin(alpha)
    return np.array([[c,-s*ca, s*sa,a*c],
                     [s, c*ca,-c*sa,a*s],
                     [0, sa, ca,d], [0,0,0,1.]], float)

def fkine(q, dh_table=DH, base=None, tool=None, offset=OFFSET):
    q = np.asarray(q, float)
    assert q.shape == (6,)
    T = np.eye(4) if base is None else np.array(base, float).copy()
    frames = [T.copy()]
    for qi, off, (a,d,alpha) in zip(q, offset, dh_table):
        T = T @ dh_matrix(qi+off, d, a, alpha)
        frames.append(T.copy())
    flange = T.copy()
    tcp = flange @ (np.eye(4) if tool is None else tool)
    return tcp, frames, flange

def is_rotation(R, atol=1e-9):
    return np.allclose(R.T @ R, np.eye(3), atol=atol) and np.isclose(np.linalg.det(R), 1, atol=atol)

class UR5:  # mô hình tối giản; nếu đã có class Robot bài 0.3, kế thừa ở đây
    dh_table = DH.copy()
    qlim = QLIM.copy()
    def fkine(self, q, base=None, tool=None):
        return fkine(q, self.dh_table, base, tool)

robot = UR5()
q = np.zeros(6)
tool = np.eye(4); tool[2,3] = .15  # kẹp dài 150 mm theo z mặt bích
T, frames, flange = robot.fkine(q, tool=tool)
assert is_rotation(T[:3,:3])
assert np.allclose(T[3], [0,0,0,1])
assert np.allclose(flange[:3,3], [-.81725,-.19145,-.005491], atol=1e-6)
P = np.array([F[:3,3] for F in frames])
fig = plt.figure(); ax = fig.add_subplot(111, projection='3d')
ax.plot(P[:,0], P[:,1], P[:,2], '-o')
ax.set(xlabel='x (m)', ylabel='y (m)', zlabel='z (m)')
plt.show()

07

Lỗi thường gặp

  • Nhân Aᵢ sai thứ tự hoặc trộn DH chuẩn với DH cải tiến.
  • Quên offset θᵢ hoặc đưa độ vào hàm lượng giác cần radian.
  • Nhầm mm với m, đọc p ở hàng cuối thay vì cột cuối.
  • Quên base/tool/TCP, so số thực bằng == thay vì np.allclose.
  • Tin kết quả số dù hình robot hoặc các hệ trung gian vô lý.
08

Tóm tắt

💡 FK: q → A₁…A₆ → T₀⁶ → T_base T₀⁶ T_tool. Lưu mọi T₀ⁱ để vẽ và debug.

Kiểm tra RᵀR≈I, det(R)≈1, các tư thế đơn giản, đơn vị và quy ước. Mẫu workspace ở trên cho thấy FK biến hàng nghìn điểm joint space thành đám mây trong task space.

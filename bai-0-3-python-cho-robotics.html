Mục tiêu bài học

Sau bài này, bạn dùng được NumPy để lưu vector/ma trận, tính FK 2R, giải hệ tuyến tính và dùng Matplotlib để kiểm hình robot.

  • Viết hàm/class có đầu vào và đầu ra rõ; kiểm tra bằng assert.
  • Vẽ tay 2 khâu với tỉ lệ trục bằng nhau.
02

Vì sao cần học?

FK, IK, DH và Jacobian ở các module tiếp theo đều là tính toán vector/ma trận. Python giúp kiểm từng bước; hình vẽ giúp phát hiện lỗi dấu, trục và đơn vị mà một ma trận in ra khó cho thấy.

💡 Một mô hình tốt trả cả vị trí khuỷu và TCP, vì đó là dữ liệu để vẽ robot và debug.
03

Khái niệm cốt lõi

1. NumPy là dữ liệu có hình dạng

np.array([1,2,3]) có shape (3,); ma trận 4×4 có shape (4,4). A[:3,:3] lấy khối xoay R, A[:3,3] lấy vị trí p. Với array, A*B nhân từng ô còn A@B nhân ma trận. Giải Ax=b bằng np.linalg.solve(A,b) ổn hơn tự tính inv(A)@b.

2. Từ góc khớp tới hình robot

q₁ là góc khâu 1 so với X đế; khâu 2 có hướng tuyệt đối q₁+q₂. Với l₁,l₂ tính bằng mét và q bằng radian:

p khuỷu=(l₁cosq₁,l₁sinq₁); p TCP=p khuỷu+(l₂cos(q₁+q₂),l₂sin(q₁+q₂))

Để vẽ: nối ba điểm gốc → khuỷu → TCP. Dùng plt.axis("equal") để một mét trên hai trục dài bằng nhau.

3. Kiểm chứng số

So hai kết quả số thực bằng np.allclose, ghi đơn vị trong biến hoặc chú thích và kiểm shape trước khi nhân ma trận. np.linalg.norm đo sai số; np.linalg.det giúp nhận ma trận suy biến.

05

Ví dụ có lời giải

  1. Cho l₁=1 m, l₂=0.8 m, q₁=30°, q₂=45°. Đổi sang radian: q₁=π/6, q₁+q₂=75°.
  2. Khuỷu: (cos30°,sin30°)≈(0.866025,0.5) m.
  3. Khâu 2 góp (0.8cos75°,0.8sin75°)≈(0.207055,0.772741) m. TCP≈(1.073081,1.272741) m.
  4. Nhập cùng tham số vào hình và chạy code Python; hai kết quả phải trùng trong sai số làm tròn.
06

Code Python

Python · NumPy + Matplotlib
import numpy as np
import matplotlib.pyplot as plt

class Robot2R:
    def __init__(self, l1, l2):
        self.l1, self.l2 = float(l1), float(l2)  # mét
    def fkine(self, q):
        q1, q2 = np.asarray(q, float)  # radian
        elbow = np.array([self.l1*np.cos(q1), self.l1*np.sin(q1)])
        tcp = elbow + self.l2*np.array([np.cos(q1+q2), np.sin(q1+q2)])
        return elbow, tcp

robot = Robot2R(1.0, 0.8)
q = np.deg2rad([30, 45])
elbow, tcp = robot.fkine(q)
print('Khuỷu (m):', elbow, 'TCP (m):', tcp)
P = np.vstack([[0., 0.], elbow, tcp])
plt.plot(P[:,0], P[:,1], '-o')
plt.axis('equal'); plt.grid(); plt.xlabel('x (m)'); plt.ylabel('y (m)')
plt.show()

A = np.array([[2., 1.], [1., 3.]])
b = np.array([1., 2.])
x = np.linalg.solve(A, b)
assert np.allclose(A @ x, b)
print('Ax=b → x=', x)
07

Lỗi thường gặp

  • Đưa độ trực tiếp vào np.sin/np.cos vốn cần radian.
  • Dùng * thay cho @ khi cần nhân ma trận.
  • Nhầm shape (3,) với (3,1); broadcasting có thể cho kết quả bất ngờ.
  • Vẽ hai trục khác tỉ lệ khiến hình robot bị méo.
08

Tóm tắt

💡 Dùng array có shape rõ, radian cho góc, mét cho chiều dài, @ cho tích ma trận và np.allclose để kiểm kết quả.
